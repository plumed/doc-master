    Actions

    Actions implemented in PLUMED Version 2.11

    The actions that can be used within a PLUMED input file are listed below.

    MATRIX ISDB_GENERIC VES_BASISF GRIDANALYSIS MCOLVAR ANNMOD_Function MATRIXF MAZE_BIAS MCOLVARF GRIDCALC DCOLVAR COLVAR FUNCTION PRINTANALYSIS VES_OPTIMIZER ISDB_BIAS MAZE_LOSS_FUNCTION TOPOLOGY EABFMOD_BIAS GENERIC BIAS MAZE_OPTIMIZER VES_UTILS OPES_EXPANSION_CV VES_BIAS REWEIGHTING VES_TARGETDIST VOLUMES VATOM ANALYSIS CONCOMP LANDMARKS ISDB_FUNCTION DIMRED ISDB_COLVAR

    MATRIX: action that calculates an adjacency matrix between atoms ISDB_GENERIC: generic tools for integrative structural and dynamical biology VES_BASISF: one-dimensional basis functions for variationally enhanced sampling GRIDANALYSIS: actions that take a function computed on a grid in input MCOLVAR: actions for calculating a vector of colvars ANNMOD_Function: function for computing a fully-connected feedforward neural network MATRIXF: actions that perform operations on input matrices MAZE_BIAS: bias for the maze module MCOLVARF: actions for calculating functions of vectors of colvars GRIDCALC: actions that output a function computed on a grid DCOLVAR: a collective variable that measures the distance between the instantaneous configuration and a reference structure COLVAR: a function of a set of atomic positions that returns a scalar FUNCTION: actions that take in one or multiple arguments and that return one or multiple arguments PRINTANALYSIS: tools for printing data that was obtained from an analysis of multiple frames of the trajectory VES_OPTIMIZER: optimizers for variationally enhanced sampling ISDB_BIAS: biases that are used in integrative structural and dynamical biology MAZE_LOSS_FUNCTION: loss function for the maze module TOPOLOGY: actions for providing information on the molecular topology EABFMOD_BIAS: bias actions for performing extended-system adaptive biasing force GENERIC: generic actions for printing and so on BIAS: bias potentials that can be used to force rare events to occur in MD simulations MAZE_OPTIMIZER: optimizer for the maze module VES_UTILS: utilities for variationally enhanced sampling OPES_EXPANSION_CV: expansion cvs that can be used with the OPES method VES_BIAS: biases for variationally enhanced sampling REWEIGHTING: actions for computing weights that can be used when calculating the unbiased distribution VES_TARGETDIST: target distributions for variationally enhanced sampling VOLUMES: actions for calculating whether atoms are within a certain part of the simulation cell or not VATOM: actions that calculate the position of a virtual atom ANALYSIS: tools for analysing trajectories CONCOMP: actions for that can be performed after you have clustered the atoms in a frame using DFSCLUSTERING LANDMARKS: tools for selecting a subset of points from an input vector/matrix ISDB_FUNCTION: functions that are used in integrative structural and dynamical biology DIMRED: dimensionality reduction algorithms ISDB_COLVAR: collective variables that are used in integrative structural and dynamical biology

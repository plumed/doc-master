    Module: replex_biasvalue

    Description Usage
    replica exchange of biases (Hamiltonian replica exchange driven by PLUMED) on 1D or multidimensional ladders
    Authors: Olivier Languin-Cattoën

    Direct native dependencies: core, tools, bias

    See module dependencies for the distinction between native dependencies and shortcut requirements.

    Details

    This module provides REPLEX_BIASVALUE, a replica exchange implementation for multi-simulation runs in which the replicas exchange their biases instead of their coordinates. The biases are linear combinations of PLUMED values, and can be arranged on a multidimensional ladder. The trajectories remain continuous in time, and the bias indices written by the action allow one to recover the ensemble of each bias.

    The module was originally developed for the paper cited below.

    Installation

    This module is compiled by default. It can be disabled with --enable-modules=-replex_biasvalue in the ./configure command used to build PLUMED.

    Usage

    The exchanges are done entirely by PLUMED, so the MD code only needs to run PLUMED on multiple replicas (e.g. mdrun -multidir in GROMACS, or plumed driver --multi), without its own replica exchange. Since only the biases differ between replicas, this is a form of Hamiltonian replica exchange that requires no change to the MD code, and that also allows ladders in more than one dimension.

    A typical input computes the CVs and the bias functions as usual, and passes them to a single REPLEX_BIASVALUE action, identical on all replicas, which adds the bias of the current replica. The bias index of each replica, written to a file, is then used to sort the trajectories by bias, e.g. with gmx trjcat -demux. See REPLEX_BIASVALUE for examples, the output files and restarts.

    Title:Enhanced sampling and cryo-EM data resolve magnesium binding to RNA

    Authors:Olivier Languin-Cattoën, Elisa Posani, Giovanni Bussi
    View a PDF of the paper titled Enhanced sampling and cryo-EM data resolve magnesium binding to RNA, by Olivier Languin-Catto\"en and 1 other authors
    View PDF HTML (experimental)
    Abstract:Magnesium ions are essential for RNA structure but difficult to model due to slow binding kinetics and experimental limitations. We present an enhanced-sampling strategy that accelerates Mg$^{2+}$ inner-shell binding by orders of magnitude, enabling quantitative exploration of ion-binding motifs in a large ribozyme. The method combines a barrier-flattening bias with Hamiltonian replica exchange to efficiently sample multiple equivalent binding sites, and builds on an approach that achieved top performance in the CASP16 blind assessment of RNA solvation structure. Using cryo-electron microscopy maps for validation, we introduce a local analysis framework that infers the population of individual binding motifs from their agreement with experimental density, enabling site-by-site validation. We find that insufficient sampling of inner-shell binding leads to significantly poorer agreement with experiment, whereas force fields predicting different inner/outer binding equilibria remain largely indistinguishable at the current experimental resolution. These results highlight the dominant role of sampling in modelling divalent ion binding and provide a general strategy for integrating simulations with experimental data in complex biomolecular systems.

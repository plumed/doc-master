    Action: TTMETAD

    Module ttsketch
    Description Usage
    Performs metadynamics with a tensor-train representation of the bias potential.

    Details and examples

    Performs metadynamics with a tensor-train representation of the bias potential.

    This action runs metadynamics while periodically compressing the accumulated Gaussian hills into a low-rank tensor train (TT) using the TT-Sketch algorithm. The TT representation keeps memory and evaluation cost bounded throughout long simulations, in contrast to standard metadynamics where cost grows linearly with the number of deposited hills.

    The basis functions of each argument are defined on [INTERVAL_MIN, INTERVAL_MAX] and are periodic over this interval. For a periodic argument the interval should thus coincide with the periodicity domain. For a non periodic argument the interval should contain the region that is explored: outside it the bias is the one at the closest limit and there is no biasing force along that argument, and hills deposited outside are folded back into the interval when they are compressed into the TT (a warning is written in the log).

    After every compression the TT is appended to the HDF5 file given by TT_FILE, and the hills file restarts empty. When restarting, the last TT in TT_FILE is read back together with the hills in FILE, i.e. those deposited after it. With multiple replicas each replica has its own TT_FILE (with the replica suffix), unless WALKERS_MPI is used, in which case the walkers share one TT_FILE next to the shared hills file. Two TTMETAD actions must use different TT_FILE.

    The hills that are not yet compressed into the TT are truncated as in METAD: at widths, and stretched so that they go to zero there, so that the bias and the forces are continuous (the environment variable PLUMED_DP2CUTOFF_NOSTRETCH switches the stretching off).

    Choosing the sketch parameters

    The method is discussed in the paper cited below. The values in parentheses are those used there for peptides biased along 2 to 14 backbone dihedral angles.

    • SKETCH_NBASIS sets the resolution of the bias. The Fourier basis (the default) contains harmonics up to , so its shortest wavelength is , where is INTERVAL_MAX-INTERVAL_MIN. This should be comparable to SIGMA (31 basis functions on , i.e. a shortest wavelength of 0.42 rad, with SIGMA between 0.25 and 0.4 rad).
    • SKETCH_INITRANK is the rank of the random sketch and should be a few times larger than the final rank (60). The final rank is best chosen adaptively with SKETCH_CUTOFF () rather than fixed with SKETCH_RANK. It grows when new minima are found and decreases as the bias converges, so final ranks (written in the log after every compression) that no longer change are a sign of convergence.
    • SKETCH_WIDTH smooths the bias at every compression, which removes high-frequency noise, but a value that is too large also smooths away the barriers. Use the largest value that does not delay the first barrier crossings in short test runs, between zero and SIGMA (0.05 rad with 6 or more CVs, zero with 2 CVs).
    • SKETCH_PACE: the hills deposited after the last compression are summed exactly, so the cost of the bias grows until the next compression, while every compression adds an approximation error. With PACE=500, the paper compresses every steps with 2 CVs and every steps (shared among 10 walkers) with more CVs.
    • SKETCH_ALPHA, KERNEL_BASIS, KERNEL_DX and NONINTRUSIVE are not used in the paper and can normally be left at their default values. Note that the Gaussian kernels of KERNEL_BASIS are also periodic over the interval, so they do not change how non-periodic arguments are treated.

    INTERVAL_MAX compulsory none Upper limits of the domain of the basis functions
    SKETCH_NBASIS compulsory 20 Number of basis functions per dimension
    SKETCH_ALPHA compulsory 0.05 Weight coefficient for random tensor train construction
    NUMERICAL_DERIVATIVESThis keyword do not have examples optional false calculate the derivatives for these quantities numerically
    KERNEL_BASISThis keyword do not have examples optional false Specifies that local kernel basis should be used instead of Fourier basis
    FMTThis keyword do not have examples optional not used specify format for HILLS files (useful for decrease the number of digits in regtests)
    BIASFACTOR optional not used use well tempered metadynamics and use this bias factor
    TEMP optional not used the system temperature - this is only needed if you are doing well-tempered metadynamics
    WALKERS_MPIThis keyword do not have examples optional false To be used when gromacs + multiple walkers are used
    WALKERS_DIRThis keyword do not have examples optional not used shared directory with the hills files from all the walkers
    RESTARTThis keyword do not have examples optional not used allows per-action setting of restart (YES/NO/AUTO)
    NO_TRIMThis keyword do not have examples optional false at a restart from a step given by the MD engine, append to the files of this action as they are, without removing the lines written at or after that step (see RESTART)
    SKETCH_RANKThis keyword do not have examples optional not used Fixed rank of the TT after every compression - compulsory if SKETCH_CUTOFF is not specified
    SKETCH_CUTOFF optional not used Relative truncation error of the singular value decompositions, which sets the rank of the TT adaptively - compulsory if SKETCH_RANK is not specified
    SKETCH_UNTILThis keyword do not have examples optional not used After this time, the hills deposited so far are compressed into the TT one last time and the bias potential freezes
    SKETCH_WIDTHThis keyword do not have examples optional not used Width of the Gaussian used to smooth the bias at every compression, one per argument
    KERNEL_DXThis keyword do not have examples optional not used Width of basis function kernels
    NONINTRUSIVEThis keyword do not have examples optional false Sketching uses previous exact sum of Gaussians instead of TT approximation
    SEEDThis keyword do not have examples optional not used Seed of the random numbers used to build the TT sketch: every sketch uses the same seed, so the results are reproducible
    DETERMINISTICThis keyword do not have examples optional false Same as SEED=42

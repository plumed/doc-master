    Action: HBONDS

    Module colvar
    Description Usage
    Calculate the number of hydrogen bonds using the Wernet-Nilsson criterion.
    output value type
    the number of hydrogen bonds scalar

    Details and examples

    Calculate the number of hydrogen bonds using the Wernet-Nilsson criterion.

    This action counts the hydrogen bonds between a set of donors (with their hydrogens) and a set of acceptors. A donor D, one of its hydrogens H and an acceptor A form a hydrogen bond according to the criterion of Wernet and Nilsson (the one used by the wernet_nilsson function of mdtraj) if

    where is the donor-acceptor distance and is the angle, in degrees, between the D-H and the D-A vectors. The criterion is a condition on a single variable,

    which has to be smaller than 0.33 nm. The step function is replaced by a switching function of , so that the CV is

    and it has continuous derivatives. The default switching function is {CUBIC D_0=0.31 D_MAX=0.35} (in nm), which is one below 0.31 nm, zero above 0.35 nm and 1/2 at 0.33 nm. You can change it with the SWITCH keyword (see LESS_THAN for the available switching functions). For instance a very sharp switching function such as {CUBIC D_0=0.3299 D_MAX=0.3301} reproduces the number of hydrogen bonds computed by mdtraj, but should not be used to bias a simulation. The angle cutoff of 45 degrees that mdtraj also applies is not needed here: at that angle the criterion already requires a donor-acceptor distance shorter than 0.24 nm.

    The donors, the hydrogens and the acceptors are given as three lists of atoms, in any order. Each hydrogen is assigned to the closest donor, which must be closer than 0.13 nm (a covalent D-H bond). This assignment is done once, on the first configuration. Hydrogens that are not bonded to any of the donors are ignored, as are the donors without hydrogens, and the number of each is written in the log. A donor that is also an acceptor does not accept from itself. An atom cannot be both in DONORS and in HYDROGENS, and an atom cannot be repeated in the same list.

    The MOLINFO shortcuts @hbdonors, @polarhydrogens and @hbacceptors select the N and O atoms bonded to a hydrogen, the hydrogens bonded to an N or an O atom and all the N and O atoms of the reference structure respectively. As in mdtraj, all N and O atoms are acceptors. In the example below all the hydrogen bonds formed within a protein are counted:

    The atoms can also be given explicitly. This input counts the hydrogen bonds in a box of 64 water molecules, in which the oxygens are atoms 1, 4, 7... and the hydrogens are the atoms that follow each oxygen.     Only N and O atoms (or other electronegative atoms) should be given as donors and acceptors: the hydrogens bonded to any atom in DONORS are used, so if a carbon was in the list its hydrogens would be donated.

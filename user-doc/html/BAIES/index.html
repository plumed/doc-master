    Action: BAIES

    Module isdb
    Description Usage
    Bayesian refinement of AF models.

    Details and examples

    Bayesian refinement of AF models.

    This action implements the Bayesian approach to refine AlphaFold (AF) models (bAIes) that is introduced in the papers cited below. It can be used to generate conformational ensembles of intrinsically disordered proteins (IDPs), as discussed in the first paper, or to refine AF models prior to small-molecule virtual screening, as discussed in the second paper.

    The distances between the pairs of atoms listed in DATA_FILE are restrained to the distributions predicted by AF. For each pair, the AF distogram is fitted with either a Gaussian distribution, in which case the energy is

    or a log-normal distribution, in which case is replaced by in the expression above. When PRIOR=JEFFREYS or PRIOR=CAUCHY is used, the uncertainty of each restraint is treated as an unknown parameter that is marginalized using a Jeffreys or a Cauchy prior, with acting as its lower bound. This results in an energy that grows more slowly than the harmonic one for large deviations and is thus more tolerant of errors in the AF predictions. PRIOR=NONE gives the energy above. SIGMA_MIN sets a lower bound for all the read from DATA_FILE. The energy is stored in the ene component.

    DATA_FILE contains one line per restrained pair, with the serial numbers of the two atoms (which must be included in ATOMS), and (in PLUMED length units, or of the logarithm of the distance for the log-normal model). The noise model is set with the model field in the header, which can be gaussian or lognormal, as in the following example:

    #! FIELDS Id atom_i atom_j mu sigma
#! SET model gaussian
0 1 16 0.23321 0.07263
1 1 23 0.56752 0.06087
2 1 29 0.81512 0.10485

    Input

    The atoms that serve as the input for this action are specified using one or more of the keywords in the following table.

    Keyword Type Description
    ATOMS atoms atoms used in the calculation of bAIes energy

    Full list of keywords

    The following table describes the keywords and options that can be used with this action

    Keyword Type Default Description
    ATOMS input none atoms used in the calculation of bAIes energy
    DATA_FILE compulsory none file with the list of atom pairs and the parameters of the fit of the AF distograms
    PRIOR compulsory none type of prior to use (NONE, JEFFREYS, CAUCHY)
    NUMERICAL_DERIVATIVESThis keyword do not have examples optional false calculate the derivatives for these quantities numerically
    NOPBCThis keyword do not have examples optional false ignore the periodic boundary conditions when calculating distances
    TEMP optional not used temperature of the system, by default the one passed by the MD engine
    SIGMA_MINThis keyword do not have examples optional not used lower bound for all the sigma values read from DATA_FILE

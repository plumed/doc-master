Detailed Description

Index of the actions, used to avoid scanning the whole set (with a dynamic_cast per action) every time a new action looks for labels, MOLINFO or atom values.

Actions are only appended to the set, so the index is extended lazily with the actions added since the last lookup. It is rebuilt if the set has been cleared.

Detailed Description

The Metainference algorithm shared by the METAINFERENCE bias and by the ISDB collective variables that inherit from MetainferenceBase.

This is not an Action: it is owned by an Action, which it uses for input parsing, communication, log, restart and status files. The owner adds its own value (the bias or the score) and calls setup() once the number of data and the experimental values are known; setup() adds the components of Metainference to the owner. At every step the owner fills data() with the back-calculated values, calls calculate() and applies the derivatives of the energy with respect to the data (getMetaDer()) and to the bias used for reweighting (getBiasDer()).

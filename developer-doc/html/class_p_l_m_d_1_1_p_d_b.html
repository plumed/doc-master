Detailed Description

Minimalistic pdb parser.

Contain positions, atomic indexes, occupancy and beta. We should also add other info (e.g. residue name etc). The same structure is filled by the reader of mmCIF files (files named *.cif or *.mmcif), see PDBCif.cpp, and by the reader of GROMACS TPR files (files named *.tpr, with chemfiles), see PDBTpr.cpp.

int & adjnum,
std::string & adjicode ) const

The residue that precedes (step=-1) or follows (step=+1) residue (resnum,icode) of chain.

It is the residue before (after) it in the file, in the same chain, if its number is resnum+step, or resnum with a different insertion code (e.g. 52 -> 52A -> 53). Otherwise it is residue resnum+step with any insertion code, as in previous versions.

Read the pdb from a file, scaling positions by a factor scale.

Files named *.cif or *.mmcif (any case) are read as mmCIF, files named *.tpr as GROMACS TPR files. The atoms are numbered as said by atomNumbering (always in the order of the file for TPR files).

Detailed Description

All the threads or one for a loop whose cost per element is not known in advance: it is measured.

The first calibrationRuns runs are serial and timed. Then the loop uses all the threads if its elements give each thread at least minMicrosecondsPerThread of serial work, estimated with the fastest serial run per element. The serial runs are always timed.

const unsigned nt=timedLoop.getNumThreads(n);
const auto start=OpenMP::TimedLoop::now();
#pragma omp parallel for num_threads(nt)
...
timedLoop.record(start,n,nt);

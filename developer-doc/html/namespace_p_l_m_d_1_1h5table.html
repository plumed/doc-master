Detailed Description

(not "h5": libraries such as ITensor use a global namespace h5)

Class for input files.

This class provides features similar to those in the standard C "FILE*" type, but only for sequential input. See OFile for sequential output.

unsigned long long PLMD::h5table::trimArchive ( const std::string & path,
double tcut,
const std::string & backup,
bool & hasTime,

Trim an archive at a restart: remove the rows from the last one with time<tcut on, moving them to backup (if not empty).

Only the members after that row are read and rewritten. Nothing is done if there is no time field (hasTime), or if the times of the rows removed would not be increasing. Returns the number of rows removed.

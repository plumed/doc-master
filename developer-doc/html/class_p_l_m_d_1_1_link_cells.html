◆ cellsFixImages()

bool PLMD::LinkCells::cellsFixImages ( ) const

Returns true if the periodic image of an atom that is within the cutoff from an atom of another cell is fixed by the cells of the two atoms.

This is the case when the cells to be searched in each direction are all different (the box is at least three cutoffs wide), and without periodic boundary conditions. The minimum image can then be found without Pbc::distance: see getView

const Pbc & pbc,

Create a neighbour list for the specified input atoms.

Parameters
natnumber of atoms
posposition of the "central atoms"
indindexes of the central atoms
tindtemporary indexes
neigh_posposition of the candidate neighbors
neigh_indindexes of the candidate neighbors
pbc
natoms_per_listoutput the number of neighbors in the longest list: each list has 1+natoms_per_list slots in nlist (the first one is for the central atom)
nlistoutput the number of atoms in each list, central atom included (nlist[tind[i]]), followed by the lists: the one of atom i starts at nat+tind[i]*(1+natoms_per_list)
applyCutoffif true only the candidates whose (minimum image) distance from the central atom is not larger than the link cell cutoff are kept, and cells of half the cutoff are used when the box is large enough (fewer candidates are visited). Without it the cells are at least as wide as the cutoff and the lists hold all the atoms of the 27 cells around the central atom, up to ~2-3 cutoffs away: with a short cutoff in a dense system most of them are beyond it. Use it only when the quantity computed from the list is exactly zero beyond the cutoff.

◆ setSubdivision()

void PLMD::LinkCells::setSubdivision ( unsigned n)

Set the number of cells per cutoff (1 or 2, the default is 1) used by the next setupCells.

With 2 the cells are smaller and those within two cells are searched: fewer atoms beyond the cutoff are visited. It is used only if there are at least five cells in each direction. The functions that work on the neighboring cells (addRequiredCells, retrieveNeighboringAtoms, and the searches on getView) take it into account

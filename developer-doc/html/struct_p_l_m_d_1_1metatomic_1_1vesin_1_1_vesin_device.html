Detailed Description

Represents a device on which data can be allocated.

This structure combines the device type (CPU or CUDA) with an optional device index. For CPU allocations, device_id is always 0. For CUDA allocations, device_id specifies which GPU to use (e.g., 0, 1, 2).

Example usage:

VesinDevice cpu { VesinCPU, 0 };
VesinDevice gpu0 { VesinCUDA, 0 };
VesinDevice gpu1 { VesinCUDA, 1 };

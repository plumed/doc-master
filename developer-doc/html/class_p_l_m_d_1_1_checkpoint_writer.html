Detailed Description

Writer for the PLUMED checkpoint file.

The checkpoint is a sequence of named, typed entries (64-bit integers, doubles, strings, and arrays of integers or doubles with a shape) grouped in nested sections. Actions write their own state in a section named after their label and never see the storage format, which is a minimal little-endian binary layout described in Checkpoint.cpp. The content is accumulated in memory and written to disk atomically by writeFile().

File names in UTF-8

PLUMED stores file names as UTF-8 strings (as the python interface passes them).

On Windows the narrow functions of the C and C++ libraries use the ANSI code page instead: these functions convert the names to UTF-16 there, and are the standard functions on the other systems. A name that is not valid UTF-8 (e.g. from a program using the ANSI code page) is read in the ANSI code page, as the narrow functions would do.

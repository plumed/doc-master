Detailed Description

Exact-restart checkpoint of a PLUMED run, configured by the CHECKPOINT action.

The checkpoint for step S captures the state at the start of S (after the update of step S-1 and before anything of S is computed) together with the sizes of all the output files after a flush at that moment. On restart the files are truncated to those sizes and the MD engine presents step S again, which is replayed in full. No action needs to know that a step is repeated.

The checkpoint is written when the MD engine sends the checkpointing signal (cmd "doCheckPoint") or, with STRIDE, every STRIDE steps. It is a separate file, one per replica (usual suffix), written atomically; the previous one is kept with a _prev suffix. If the MD engine never sends the signal, a checkpoint of the state after the last step (i.e. for the next step) is written at the end of the run (cmd "runFinalJobs", or the destructor of PlumedMain), with a _final suffix.

◆ atRunEnd()

void PLMD::Checkpointing::atRunEnd ( bool fromDestructor = false)

At the end of the run (cmd "runFinalJobs", before the final jobs, or, if it was not called, when PLUMED is finalized, fromDestructor): if the MD engine never sent the checkpointing signal, write the state after the last step, i.e.

at the start of the next one, to FILE with the suffix _final (plumed_final.cpt). Only the first call does something; nothing is written if the last step was not completed or, from the destructor, if MPI is already finalized.

◆ trimAtRestart()

void PLMD::Checkpointing::trimAtRestart ( const std::string & fileName,
bool keepRestartStep = false )

Remove from a file the lines written at or after the restart step, i.e.

the last lines whose time is not smaller than the time of the restart step (the earlier lines, also those of earlier runs whose time restarted from zero, are kept). Files without a time field, compressed files, and files where the time of these lines is not increasing are left as they are, with a line in the log. Each file is processed only once. To be called by one process only, before the file is read or written by this run (see OFile). keepRestartStep: the lines of the restart step itself are kept (e.g. the hill of that step, when the bias is read from a grid written at the checkpoint).

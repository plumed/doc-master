Detailed Description

The GPU used by the actions that run on a GPU.

PLUMED itself does not use GPUs: the actions that do are in plugins and modules compiled with another toolchain (plugins/openaccPTM, src/gpu_cuda_hip), each with its own runtime (OpenACC, CUDA or HIP). They all choose the GPU here, so that they make the same choice and write it in the log in the same way. The plugin tells what its runtime sees, and gets the number of the GPU to use, the first that applies of:

  1. the GPU assigned to PLUMED by the MD code (cmd "setGpuDeviceId"), if it is one of the GPUs the runtime sees;
  2. the GPU the MD code is using in the thread that calls PLUMED (for CUDA, the device of the current context), when the plugin can tell;
  3. the GPU chosen by the user for the runtime (e.g. with ACC_DEVICE_NUM);
  4. with more than one GPU, and the rank of the process within its node known from the MPI launcher, the GPU number rankngpus: the processes of a node share its GPUs in turn (e.g. plumed driver with MPI);
  5. the GPU the runtime uses by default.

GPUs are numbered as the runtime does: with CUDA_VISIBLE_DEVICES all the runtimes see the same GPUs.

Detailed Description

Counter-based random numbers: Threefry2x64-20 (Salmon, Moraes, Dror and Shaw, "Parallel random numbers: as easy as 1, 2, 3", SC'11; the Random123 library).

Each 128-bit output block is a function of a 128-bit key and a 128-bit counter only, and any keys and counters (also consecutive ones) give independent numbers. This gives reproducible numbers without storing a state, e.g. one stream per step with restart(step), as GROMACS does for replica exchange.

Read the bias from a grid file (METAD: GRID_RFILE, PBMETAD: one of GRID_RFILES), on the lattice of the grid given in input (see MetaDBiasGrid::read).

With WALKERS_MPI, a relative path is in the directory of the first replica, so that all the walkers read the same file. Returns the numbers of hills of the other walkers in the grid (WALKERS_N, see MetaDHillsFiles::getGridComment), or an empty vector.

◆ readHillsAtStart()

void PLMD::bias::readHillsAtStart ( Action & action,
MetaDWalkers & walkers,
const std::vector< MetaDHillsInput > & inputs,
bool restartedFromGrid,
MetaDHillSchedule & schedule )

Open the hills files of all the walkers when the action starts, and read them:

  • with RESTART, the hills of all the files are added to the bias (a missing file is an error);
  • with RESTART and the bias read from grid files, the hills files of this walker are scanned, for the time of the last hill and for the statistics of ADAPTIVE=DIFF, and the hills of the other walkers that are not in the grids are added (WALKERS_N: their numbers are in the grid files; for older grid files, those up to the last hill of this walker are assumed to be in the grids). The time of the last hill of the files of this walker is given to schedule (with WALKERS_MPI, the same for all the walkers). Then the incomplete last line of these files (an interrupted run) is removed, and they are closed, to be written. With WALKERS_MPI and no WALKERS_DIR, the files with a relative path are in the directory of the first replica (walkers.dir is set). To be called by all the processes of all the replicas.

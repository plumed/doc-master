Detailed Description

template<typename T>
class PLMD::bias::ThreadWorkArrays< T >

Work arrays of the OpenMP threads, written at every hill or grid point.

When two threads write in the same cache line (false sharing), or one writes where another one reads, both become much slower, and using more threads can take longer than using one: this happened with small vectors allocated by each thread, depending on where the heap placed them. Here the arrays of all the threads are in a single allocation, separated from each other and from the ends of the allocation by 128 bytes that are never used.

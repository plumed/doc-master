Detailed Description

Identifiers of the ONEBEAD bead types and of the monoatomic ions, with the residue-name helpers that classify the residues of an all-atom structure.

The enumerators are used as indices of parameter tables (e.g. the SAXS/SANS form factors), so their order must not change.

bool hasN )
static

The GLYC_* bead type of a monosaccharide residue name, or -1 if the residue is not a supported glycan.

hasN must be true when the residue carries an amide nitrogen: that is what distinguishes GlcNAc from Glc and GalNAc from Gal when the input file names an N-acetylhexosamine after its parent hexose.

Detailed Description

Interface of an accelerated (e.g.

GPU) implementation of the Debye sum of SAXS/SANS.

The backends live in plugins (see plugins/openaccPTM) and are selected with the USEGPU keyword of SAXS/SANS. All the rest of the calculation (form factors, self term, resolution function, metainference) stays in SAXS.

For n particles at positions r_i, with form factors f_i(q_k), a backend computes

\[ I_k = \sum_{i} \sum_{j\neq i} f_i(q_k) f_j(q_k) \frac{\sin(q_k r_{ij})}{q_k r_{ij}} \]

(the self term \(\sum_i f_i^2\) is added by SAXS) and its derivatives with respect to the positions. The work is split over the ranks: each rank computes the contributions of the rows i = first, first+stride, ... and SAXS sums the results of all the ranks.

Computes the contributions of the rows i = first, first+stride, ... < pos.size().

ff[i*q.size()+k] is the form factor of particle i at q[k]. The partial intensities are added to sum (q.size() elements). If deriv is not null, the derivatives of I_k with respect to r_i are added to (*deriv)[k*pos.size()+i] (q.size()*pos.size() elements). The derivatives are kept for the next call to contract().

Detailed Description

ADAPTIVE=DIFF: when restarting, the statistics of the fluctuations of the variables (running average and covariance) are initialized from the last hills of this walker in its hills file.

The hills are kept here while the file is read, until the first update, when the current time is known.

The statistics from the hills of this walker.

The hills with times within tol form blocks (one deposition): with blocksize 0 all the hills are used, otherwise the hill at position offset of the blocks with blocksize hills. Only the hills up to now, and the last sequence with increasing times, are used. The covariance is that of the last hill; the average is the average of the centers with the exponential weights of the running average (decay per update, updatetime is the time between updates). difference(i,a,b) and bringBackInPbc(i,x) are those of variable i. Returns the number of hills used (0: no statistics), and the time of the last one.

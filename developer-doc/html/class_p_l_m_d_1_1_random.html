Detailed Description

Random number generator used everywhere in PLUMED.

The engine is xoshiro256** (Blackman and Vigna), 64-bit output, period 2^256-1, seeded from a single integer with splitmix64. The conversions to uniform doubles, Gaussian numbers, bounded integers and shuffles are implemented here (not with the std:: distributions), so that a given seed gives the same stream on every compiler and standard library.

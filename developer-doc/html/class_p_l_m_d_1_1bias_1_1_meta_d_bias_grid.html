Detailed Description

The grid on which METAD and PBMETAD accumulate their hills.

The grid is extended along the variables that are not periodic whenever a hill does not fit in it, so that it always contains all the points where the hills are not zero (plus one point on each side): the bias is zero outside the grid. The spacing does not change and the new points are on the same lattice. With INTERVAL (one dimensional only) the bias beyond the limits is constant: the grid contains the interval and at least one point beyond each limit, and the bias beyond the grid is the value at its ends.

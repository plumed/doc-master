Detailed Description

The hills files of METAD and PBMETAD for a set of arguments: writing of the hills, and reading of the files of a restart or of the other walkers.

With several MPI processes the files are opened and read by the first process only, which also decides if they exist, and the hills are broadcast to the others: the file of another walker can grow while it is read, and if each process read it they could read a different number of hills, and their biases would differ. The file operations do not synchronize the processes (the files are linked to a communicator of the process alone). Everything written on the log is written by all the processes.

Read the hills of file i that are in the file up to now (an open file) and add them to the bias, writing their number on the log (the caller has started the line).

Returns their number. lasttime: if given, the time of the last hill is returned, and the hills are kept for ADAPTIVE=DIFF (own file); addtobias: false to only scan the file; the hills up to time skipupto, and the first skipcount, are not added (they are already in the grid read from file)

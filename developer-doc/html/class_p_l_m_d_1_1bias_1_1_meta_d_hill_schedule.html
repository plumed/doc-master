Detailed Description

The steps when a hill is added: every stride steps, except the first step of a run.

At step 0 no hill is added (also when the bias of a previous simulation is read with RESTART). When continuing a simulation, the hill is not added only if the hills file already contains it, i.e. if the previous run already performed this step (some MD codes compute again the last step of the previous run when restarting, others do not).

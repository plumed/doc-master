Detailed Description

Event notification wait and signaling functions.

The event structure offers lightweight signaling and scheduler-yielding (but still spinning) waiting for waits of intermediate durations (i.e. longer than appropriate for a spin lock but shorter than mutex_cond_wait(). These functions only take care of the waiting and signaling; the user is responsible for the handling of the actual event structures and condition variables.

Detailed Description

Reader for the PLUMED checkpoint file written by CheckpointWriter.

The whole content is parsed on construction, which detects truncated or corrupted files. Entries are then accessed by name, relative to the current section; unknown entries and sections are ignored, so that newer files can be read by older code as long as the entries they need are present.

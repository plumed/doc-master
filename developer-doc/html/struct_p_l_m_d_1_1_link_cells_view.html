Detailed Description

The link cells built by LinkCells, as a plain struct that can be copied to a GPU: the geometry of the cells and pointers to the arrays of one LinkCells::CellCollection (which must have been built with its positions).

It does not own the arrays: it is valid until that collection is rebuilt. Get it with LinkCells::getView, and search it with forEachCandidate or forEachNeighbor

Detailed Description

template<typename Visitor>
struct PLMD::LinkCellsNeighborFilter< Visitor >

Calls visit(atom,d,d2) for each atom within the cutoff from the position pos, except the atom self (use std::numeric_limits<unsigned>::max() to visit all), in the order of the cells.

atom is the index stored in the cells, d the minimum image vector from pos to the atom and d2 its squared modulus. visit is a functor
